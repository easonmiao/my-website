# HooMee No.3 page topology

## Shared

- Floating pill navigation: logo, 科技·资讯, 生活·记录, 萌宠·探索, 关于,
  and No.3 return/search-style action.
- Shared multi-column footer: HooMee summary, 栏目, 功能, 归档.

## Secondary listing pages

Routes: `/tech/`, `/life/`, `/pets/`, `/memories/`.

`navigation → featured editorial split → More Stories grid → footer`

## Secondary long-form pages

Routes: `/about/`, `/tujie/`.

`navigation → oversized pale-blue hero → media/banner → feature sections →
FAQ/details → footer`

`/tujie/` inserts the existing functional generation workflow between hero
and explanatory features.

## Tertiary article pages

Routes: `/articles/**`.

`navigation → back link → title → author → cover → date → prose sections →
related reading → footer`

Historical content under `/memories/previous-site/**` is an archive and must
not be rewritten by this page system.
