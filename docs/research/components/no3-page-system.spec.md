# HooMee Coffee No.3 二级与三级页面系统规范

## 范围

统一以下活跃页面，不改动历史快照目录中的旧站视觉：

- 二级：`/tech/`、`/life/`、`/pets/`、`/about/`、`/memories/`、`/tujie/`
- 三级：`/articles/ai-morning/2026-07-06/`

## 母版视觉

- 以 `/no3/` 为母版：浅蓝柔光背景、白色悬浮导航、深海军蓝正文、彩虹渐变强调、24–30px 大圆角、轻柔阴影、宽松留白。
- 字体使用现有系统无衬线字体；任何强调文字都不使用斜体。
- 导航统一使用 HooMee Coffee 横版 Logo、科技·资讯、生活·记录、萌宠·探索、关于、回到 No.3。
- 页面背景加入低对比度蓝紫桃色径向柔光，不遮挡正文。

## 二级页面

- Hero 维持现有内容与图片，但放进白色圆角母卡；图片为大圆角，文字使用 No.3 的眉题、48–72px 标题和柔和正文色。
- 内容列表改为 Portrait 式白色卡片：图片上方、文字下方，悬停轻微上浮，不添加陌生内容。
- 科技、生活、萌宠各自保留栏目色，只通过柔光底色区分。
- 关于页三位主理人卡片、回忆页两个档案入口使用同一圆角和阴影体系。
- `memories/previous-site/**` 是历史存档，不改其内部样式。

## 三级文章页

- 文章详情保持可读宽度 760–820px，顶部有同款悬浮导航。
- 正文置于白色圆角阅读卡；标题、导语、封面、二级标题、列表和返回按钮统一 No.3 样式。
- 文章段落行高不低于 1.85，移动端字号不低于 16px。

## Tujie

- 保留图解工具全部功能、表单与弹窗结构。
- 只统一顶栏、页面背景、主卡圆角、深蓝文本、彩色强调与按钮视觉；不得破坏输入、设置、生成和下载交互。

## 品牌、响应式与验收

- 活跃页面的可见品牌称呼统一为“HooMee Coffee”。
- 桌面 1440px 与移动 390px 均无横向滚动；触控按钮高度至少 40px。
- 导航在移动端允许横向滚动，但 Logo 始终可见。
- 所有现有链接继续可访问；历史快照链接保留。
